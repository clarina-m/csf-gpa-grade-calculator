How your GPA is calculated

Unweighted: A = 4.0 (90-100), B = 3.0 (80-90), C = 2.0 (70-80), D = 1.0 (60-70), F = 0 (below 60)

Weighted: there is one point added for Honors and AP courses (ex A = 5.0), but the same policy above for College Prep courses.
